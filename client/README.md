# Campus Lost & Found — Client Application

React 19 single-page application built with Vite and Tailwind CSS.

### Scripts
- `npm run dev`: Start Vite development server on `http://localhost:5173` (proxies `/api` and `/uploads` to port 5000)
- `npm run build`: Compile production bundle to `dist/`
- `npm run preview`: Preview built production bundle

See root [`README.md`](../README.md) for full project architecture and documentation.
