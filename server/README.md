# Campus Lost & Found — Backend REST API

Node.js + Express REST API backed by MongoDB and Mongoose ODM.

### Scripts
- `npm start`: Start Express server on port 5000 (serves REST API and compiled frontend)
- `npm run dev`: Start development server with file watch
- `npm run seed`: Populate MongoDB with demo students, lost/found items, claims, and admin
- `npm test`: Run automated test suite with Node's native test runner

See root [`README.md`](../README.md) for full endpoint specifications and architecture.
